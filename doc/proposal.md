# 提案：完美鎖步的相位驅動 IK 行走系統 (Phase-Driven IK Locomotion)

## 1. 問題分析
使用者反映目前的行走動畫「看起來像倒退走」、「步伐沒有交叉」且「缺乏真正的跨步感」。
這是因為之前的 Procedural Stepper 是基於「偏離理想位置太遠才跨步」的邏輯，導致：
1. 左右腳的理想位置太近，無法產生大幅度的交替跨步（Stride）。
2. 在跨步前，腳雖然會鎖在世界座標，但因為缺乏整體的步伐循環 (Walk Cycle) 控制，導致沒有「邁開步伐」的動態感。
3. 腳的抬起與放下沒有與骨盆的前進速度完美同步，產生了滑步或倒退走的錯覺。

## 2. 解決方案：相位驅動 (Distance-Matching Phase)
為了達成「絕對不滑步」且「雙腳主導移動」的完美火柴人動畫，我們將採用進階的 **距離匹配相位器 (Distance-Matching Phase)** 技術：

### 2.1 核心概念
- 不再使用 `delta * speed` 來無腦累加時間，而是直接使用 **角色的絕對 X 座標** 來計算「行走相位 (Phase)」。
- 相位 $p$ 永遠介於 $0.0 \sim 1.0$ 之間。每前進一段固定的「步長 (Stride Length)」，相位就完整循環一次。
- 左腳與右腳的相位永遠相差 $0.5$（也就是 $180^\circ$），這保證了**絕對完美的交替跨步**，雙腳必定會在身體下方交叉！

### 2.2 分段步態設計 (Piecewise Gait)
針對每一隻腳，我們將 $0.0 \sim 1.0$ 的相位分為兩個階段：
1. **支撐期 (Stance Phase, 0.0 ~ 0.5)**：
   - 腳精準地貼在地面上。
   - 腳相對於身體的 X 座標會從 $+S/2$ (前方) 等速往後退到 $-S/2$ (後方)。
   - 因為退後的速度完全抵銷了身體前進的速度，所以**在世界座標系中，這隻腳會像被釘死在地上完全不動**！這就是真正的雙腳驅動感！
2. **擺盪期 (Swing Phase, 0.5 ~ 1.0)**：
   - 腳從地面抬起。
   - 腳相對於身體的 X 座標會從 $-S/2$ (後方) 快速甩到 $+S/2$ (前方)。
   - 同時 Y 座標會產生一個拋物線（利用 sine 函數），形成完美的抬腿跨步動作。

### 2.3 骨盆與軀幹連動
- 當相位在 $0.25$ 或 $0.75$ 時（雙腳張最開），骨盆下沉 (Bobbing)。
- 軀幹依然會根據移動速度適度前傾 (Lean)。

### 2.4 雙膝 IK (Inverse Kinematics)
- 保留雙節點 IK 數學解算，確保大腿與小腿的彎曲完美銜接骨盆與腳跟，徹底消除任何拉伸與破圖。

## 3. 預期效果
- **絕對零滑步**：腳踩在地上的期間，世界座標絕對靜止。
- **完美的交叉步**：左腳與右腳必定會交替邁步。
- **支援任意速度與轉向**：由於相位是綁定 X 座標，無論玩家是急停、加速還是反向走，動畫都會在任何一幀完美對應，不會有慣性帶來的鬼畜抖動。
